# Oyamatsumi
Customizable vein miner

# Commands
## Normal User
`/miner`: Toggle mining mode

## Admin
- `/miner force-on <UUID or PlayerName>`: Force on a specified players mining mode
- `/miner force-off <UUID or PlayerName>`: Force off a specified players mining mode
- `/miner flush`: Flush player mining mode status to a config file
- `/miner load`: Load mode status from a config file if exists
